About 404 / 301 checking

The checks above run instantly and need no internet. They catch your most common fixes: internal links left as full healthdirect.gov.au URLs (which 301-redirect), insecure http://, empty or placeholder links, broken on-page anchors, and external links missing target="_blank".

The live check below fetches every link through a proxy to find dead links (404) and links that now redirect somewhere else. Each link is checked one at a time with a short wait between requests, and each request times out on its own, so a long list won’t fire all at once or hang.

Default proxy returns the real HTTP status and the final URL after any redirect. The {url} placeholder is replaced with each link. Wait between requests and per-request timeout are set below in the code if you want to change them.

How to use these in Optimizely

Title / ID: paste these into the section’s heading and anchor-ID fields. The ID is auto-generated for now — a proper matched-ID list can be wired in later.

Body — Copy for Optimizely puts the segment on your clipboard as rich content, so formatting and links come across; Copy source copies the raw HTML for the field’s HTML/source view. If a Copy button ever fails (some browsers block it on file://), use Select all and press Ctrl/Cmd+C.

Key facts: the field takes only <li> items and pastes as text — use Copy source (or Copy for Optimizely) and paste into the list field.

Callout boxes: the green note at the bottom of a section names the shared block to drag in there. Nothing to paste — it’s a placement reminder.

Source references: formatted as “Organisation — Page name (link) (Authors)”. Built from the references table in your pasted content, so the page links are kept.

For a relative link to resolve to a page, the field must be on the matching site and the editor’s paste-time link handling must be switched on. If a link comes in as plain text, paste into the source view instead.
